\chapter{无线 IoT 系统}
\label{chap:wireless-iot}

无线 IoT 系统同时受射频链路、功耗、网络拓扑、安全身份和云端生命周期约束。选择无线协议不能只比较标称速率和距离，还要评估频谱环境、节点密度、待机时间、网关依赖、认证要求和量产测试能力。

Matter 是基于 IP 的应用层互操作体系，可运行在 Wi-Fi、Thread 和以太网上，并通常使用 BLE 完成初始配网\cite{matter-spec}。它不能替代底层无线链路设计，也不会自动解决天线、共存和设备生命周期问题。

\section{射频与天线基础}

链路预算由发射功率、天线增益、路径损耗、接收灵敏度和实现余量共同决定：
\begin{equation}
  P_{rx}=P_{tx}+G_{tx}+G_{rx}-L_{path}-L_{misc}
\end{equation}

PCB 天线必须遵守参考设计的板厚、介质、净空和地平面要求。外壳、电池、屏幕、排线和人体都会改变谐振与方向图，最终产品必须进行传导与辐射测试，不能只验证裸板 RSSI。

2.4~GHz Wi-Fi、BLE、Thread 和 Zigbee 共用频段。共存设计需要信道规划、收发仲裁、天线隔离和流量调度；双无线芯片若缺少硬件共存接口，软件高负载时可能出现明显丢包和延迟长尾。

\section{低功耗连接}

平均电流由各状态电流与驻留时间加权：
\begin{equation}
  I_{avg}=\frac{\sum I_i t_i}{\sum t_i}
\end{equation}

无线发送往往只占很短时间，实际寿命可能由连接保持、频繁扫描、晶振启动、传感器预热和电源静态电流决定。必须用电流分析仪测量完整业务周期，而不是用芯片数据手册中的深睡电流直接估算整机寿命。

BLE connection interval、slave latency、Wi-Fi DTIM、Thread sleepy end device 轮询周期和蜂窝 PSM/eDRX 都是在延迟、可靠性和功耗之间取舍。云端心跳周期也属于设备电源设计的一部分。

\section{配网与设备身份}

配网是建立设备身份、网络凭据和管理权限的安全过程。产品应使用每设备唯一身份和一次性或受保护的 onboarding 信息，避免全产品共享默认口令。

推荐流程包括：
\begin{enumerate}
  \item 用户通过物理动作使设备进入有时限的配网状态；
  \item 管理端验证设备证明或出厂身份；
  \item 双方建立认证加密通道；
  \item 在通道内传递网络凭据和访问控制信息；
  \item 设备验证网络并持久化最小必要配置；
  \item 配网窗口关闭，失败尝试具有速率限制和审计记录。
\end{enumerate}

恢复出厂设置必须明确删除哪些网络凭据、用户数据和设备密钥。设备根身份是否允许删除，取决于重新入网和所有权转移模型。

\section{协议栈与应用边界}

无线驱动、链路层、IP、传输安全、消息协议和业务状态机应分层。应用不应依据 RSSI 单值直接判定在线，也不应把一次 socket 成功写入视为云端已处理。

MQTT 等发布订阅协议需要明确 QoS、会话持久性、重复消息和 retained message 的业务语义。所有可能重复投递的命令都应带消息 ID 或幂等键；设备端离线队列必须有容量上限和淘汰策略。

\begin{lstlisting}[language=C,caption={可重试 IoT 命令的抽象结构}]
struct cloud_command {
    uint64_t command_id;
    uint32_t schema_version;
    uint32_t expires_at;
    uint16_t operation;
    uint16_t payload_length;
    uint8_t  payload[MAX_PAYLOAD];
};
\end{lstlisting}

设备应拒绝过期、版本不支持和已执行的命令，并返回可区分“已执行”“暂时失败”和“永久拒绝”的结果。

\section{安全更新与证书生命周期}

无线设备通常长期处于非可信网络中，必须具备安全启动、签名 OTA、防回滚、证书轮换和漏洞响应能力。TLS 只保护传输通道，不能替代固件签名和本地授权。

证书生命周期应覆盖生产注入、首次注册、续期、时间不可信时的启动、吊销、所有权转移和设备报废。设备实时时钟未同步时，不能简单地关闭证书时间验证；应设计可信时间来源或受限的首次连接流程。

\section{法规、认证与量产测试}

无线产品需要考虑目标市场的频谱法规、发射功率、带外辐射、SAR/暴露限制以及联盟认证。使用预认证模组可以降低风险，但天线、布局、外壳或射频参数变化仍可能要求重新测试。

量产测试应覆盖晶振偏差、发射功率、接收灵敏度或简化替代指标、天线连接、设备身份和 MAC 地址唯一性。测试模式必须受控，交付固件不应留下未经授权即可进入的连续发射接口。

\section{验证清单}

\begin{itemize}
  \item 协议选择是否基于业务周期、覆盖、节点密度和电池预算？
  \item 天线是否在最终外壳、电池和线缆状态下测量？
  \item 断网、弱信号、AP 重启、网关迁移和凭据失效能否恢复？
  \item 配网、所有权转移和恢复出厂是否具有明确安全边界？
  \item 离线队列、重复消息和命令过期是否具有确定语义？
  \item OTA、证书轮换和报废流程是否经过端到端演练？
  \item 功耗测量是否覆盖真实连接、重传和环境边界？
\end{itemize}
